A program that draws the passport spread of the Republic of Virelia,
a country that isn't there: a data page (coat of arms, photograph,
personal details, signature, machine-readable zone) and a visa page
(a drawn map of the island, arrival and departure stamps, a granted
visa). Pure Python standard library, deterministic — two runs produce
a byte-identical 1024x1024 PNG.

## Run it

```sh
python3 main.py
```

Writes `entry.png` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
